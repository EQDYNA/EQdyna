OPEN (2026-09-16): **grid-scale stress ringing at 500 m is stabilised but not damped.** After the rupture front passes, on-fault shear rings at ~1.4-3.2 Hz with 0.7-5.6 MPa peak-to-peak. `Vs/(2*dx) = 3.46 Hz` at dx=500 m, so this is the mesh's shortest resolvable wavelength. MEASURED, post-arrival window [t_arr+0.15, t_arr+1.6] s, linear detrend only: tpv36 (wedge) 0.68 MPa / 3.17 Hz / 1.67 pct of peak tau; tpv37 (wedge) 0.76 / 2.58 / 1.77; **tpv10 (hex, dipping) 5.60 / 2.37 / 9.49**; **tpv104 (hex, vertical) 4.79 / 1.41 / 5.86**; tpv8 (hex, vertical) **0.004 / 1.39 / 0.01** -- essentially ring-free. WHY IT IS NOT SUPPRESSED, and this part IS settled: the default hourglass control is `C_hg=1`, KF78, STIFFNESS-based and non-dissipative by construction. Its only damping is the Rayleigh term inside the hourglass force, `dl = disp + rdampk*vel` with `rdampk = 0.1*dt` (`readInputFiles.f90:133`), giving zeta = 0.5*(0.1*dt)*omega_grid = **0.0065, i.e. 0.65 pct of critical**, an e-folding after ~24 cycles. The mode cannot grow but barely decays. AND ZETA IS RESOLUTION-INDEPENDENT: `rdampk ~ dt` while `omega_grid ~ 1/dx ~ 1/dt`, so they cancel -- 0.65 pct at both 500 m and 50 m. Refining does NOT damp this mode; it moves it to a band carrying less energy, which is why the published 50 m run looks flat rather than being better damped. THE LEAD: `C_hg=2` is a genuine VISCOUS hourglass control (`kapa_hg=0.1`, Goudreau and Hallquist 1982) that IS dissipative, and **no case in this repo sets it** -- that path has never been exercised. One run of tpv37 with `C_hg=2` would say whether it damps this at the default kapa_hg. WHAT IS NOT KNOWN: why the amplitude varies 1000x across cases (tpv8 0.01 vs tpv10 9.49). Element type is NOT the discriminator -- the degenerate-wedge cases ring LESS than two of three hex cases, and a degenerate wedge is still an 8-node element of the same shape family, so the hex hourglass modes apply normally. friclaw, dip, insertion-vs-degeneration and nucleation sharpness are all confounded at n=3-9 stations per case. Three mechanisms were proposed and measured WRONG before this (front element-crossing, wedge hourglass mismatch twice); do not add a fourth without a controlled experiment. CONSEQUENCE FOR THE GATE: the 500 m reference files CONTAIN this ringing, so the sweep compares ringing against ringing and is structurally blind to it. Acceptable for a regression check; not an accuracy claim. **UPDATE 2026-09-17 (dunyu-liu, model sonnet, this session -- relayed, NOT independently re-run by the orchestrating session; treat as a hypothesis carried from her report until independently reproduced, same disclosure pattern as item 40):** C_hg=2 (the viscous hourglass control this row's "lead" section names) was measured on `test.tpv37` and does NOT work as a drop-in fix at its only implemented coefficient (`kapa_hg=0.1`, hardcoded in `src/fortran/calcHourglassResist.f90`).
