`PROJECT_RULES.md` for the rules each item enforces. History (what shipped,
when) lives in `pastReleaseNotes.md` and `README.md` — this file does not
duplicate it and is not append-only; items are updated or closed in place.

actually runs the command.

**Struck-through (resolved) rows record the state AT THE TIME they were
closed**, so they name files that have since been deleted or moved -- notably
`check.test.py`, `testAll.py`, `src/pydump.f90`, the `accept` and `parity`
tiers, and the pre-restructure Python module names (`port_rsf.py`,
`kernels_numpy.py`, `standalone/main.py`). That is history, not drift, and it
is not rewritten. The `Command` column of an OPEN row, by contrast, must run
today -- if one does not, that is a bug in this file.

Python solver is `src/python/eqdyna/` (14 modules, one per Fortran file), and
